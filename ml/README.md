# ML-сервис: city и region

Контракт для backend-разработчиков: [все эндпоинты, форматы запросов и ответов, ошибки и миграция клиента](API_README.md).

Основные модели: city на основе city_filtered_5 **без итогового кода холестерина** (25 признаков) и region (26 признаков). Экология назначается по району и периоду; ID пациента не используется в признаках или подборе экологии.

## Запуск

Из каталога ml:

```bash
uv sync --frozen --no-dev
uv run --frozen --no-dev uvicorn app.main:app --host 0.0.0.0 --port 8000
```

В Windows PowerShell, если uv установлен через Python:

```powershell
py -m uv sync --frozen --no-dev
py -m uv run --frozen --no-dev uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Для разработки: `uv run uvicorn app.main:app --reload`. Точка входа — app.main:app, запуск python main.py из ml/app не запускает сервер.

## Датасет для /retrain

Датасет содержит закрытые данные пациентов и не хранится в Git. Файл `app/data/train_dataset.csv` нужно предоставлять локально или загружать через `/retrain`.

Локальный файл `app/data/train_dataset.csv`: **2987 строк, 69 столбцов**, одна строка на пациента. В нём нет model_kind, отдельного year и target. Обследования и исходы разных лет хранятся в столбцах одной строки. Сервис сам рассчитывает записи по годам, составные целевые метки и экологические признаки.

`GET /dataset/schema` и `app/data/dataset_schema.json` содержат полный список столбцов и кодировки. Схема CSV — 6, схема predict — 5.

- id — непустой уникальный идентификатор для группировки выборки.
- район, город 1 /село 2 — территория; 1 — город, 2 — село.
- возраст, пол, профессия, алкоголь и хронические заболевания лёгких — исходные данные 2013 года.
- рост, вес, общий холестерин, ЛПВП, ЛПНП и ТГ — показатели 2013 и 2019–2021.
- глюкоза — показатель 2019–2021.
- диагнозы, госпитализации и смерти по годам/периодам — исходные известные значения 0/1 для расчёта целевых меток.

Возраст, рост и вес обязательны; лабораторные пропуски допустимы. Неизвестные исходы не подменяются нулями. Разделитель — запятая, UTF-8, десятичная точка. Дополнительные исходные столбцы игнорируются; готовые model_kind/year/target во входном CSV отклоняются.

Объём бёдер, не-ЛПВП, ЛПОНП, аполипопротеины A/B и итоговый код холестерина в подготовленном файле отсутствуют. Хронические заболевания лёгких включены. Исходный new_patients.csv можно загрузить напрямую: сервис выберет нужные столбцы.

Пол: муж/жен или 1/2. Алкоголь: нет/употреблял ранее/да в настоящее время или 0/1/2. Профессии в CSV принимаются названиями, исходными вариантами из блокнота либо кодами 1–13:

| Код | Категория |
|---:|---|
| 1 | Руководители и представители власти |
| 2 | Специалисты высшего уровня квалификации |
| 3 | Специалисты среднего уровня квалификации |
| 4 | Служащие по подготовке и оформлению документации |
| 5 | Работники сферы услуг, охраны и продавцы |
| 6 | Квалифицированные работники сельского/лесного хозяйства, рыбоводства |
| 7 | Рабочие промышленных предприятий, строительства и транспорта |
| 8 | Операторы установок и машин, сборщики |
| 9 | Неквалифицированные рабочие |
| 10 | Военнослужащие |
| 11 | Пенсионер |
| 12 | Ведение домашнего хозяйства |
| 13 | Другое |

Старые объединённые профессии из patients.csv нельзя однозначно разделить; используйте new_patients.csv или исходные раздельные значения. Неизвестная профессия не заменяется категорией «Другое».

Воспроизводимая подготовка и обучение:

```bash
uv run python -m app.services.dataset --patients-csv /path/to/new_patients.csv --output app/data/train_dataset.csv
uv run python -m app.services.retrain --dataset app/data/train_dataset.csv
```

## Эндпоинты

### POST /retrain

Multipart-поле dataset принимает исходную широкую таблицу:

```bash
curl -X POST http://localhost:8000/retrain -F dataset=@app/data/train_dataset.csv
```

Сервис создаёт обследования city 2013/2017/2019/2021, исключает записи после смерти, рассчитывает возраст и выбирает клинические показатели нужного обследования. Для region формируется одна сводная запись со средними весом, ростом и липидами. Затем рассчитываются цели, экология, ИМТ и взаимодействия.

Ответ: status, saved_models (city_model.cbm и region_model.cbm), model_version, metrics, input_patients и prepared_rows. В текущем датасете получаются 11789 записей city и 2987 region.

Ошибки данных — 422, параллельное переобучение — 409, превышение размера файла — 413. Во время обучения predict обслуживает активную версию; неудачное обучение её не меняет. Временный загруженный файл удаляется.

### POST /predict

Также доступен /predictions/predict. Один запрос содержит одно обследование или сводную запись. Поля model_kind и year здесь выбирают модель и экологический период; они не требуются во входном CSV для retrain.

```json
{
  "model_kind": "city",
  "year": 2021,
  "gender": 1,
  "age": 55,
  "height": 175,
  "weight": 80,
  "alcohol": 0,
  "profession": 2,
  "region": 5,
  "chronic_lung_disease": 0,
  "glucose": 5.7,
  "cholesterol": 5.2,
  "hdl_cholesterol": 1.5,
  "ldl_cholesterol": 3.4,
  "triglycerides": 1.2
}
```

Для region передавайте model_kind=region, year=null и сводные клинические показатели. Районы: 1 — Рудничный, 2 — Центральный, 3 — Заводский, 4 — Кировский, 5 — Ленинский, 6 — сельская местность.

Примеры: examples/predict_city.json и examples/predict_region.json. Поле cholesterol_status исключено из API. ID, target, экологические показатели и удалённые поля передавать не нужно. Необязательная история диагнозов не используется как признак составной цели.

```bash
curl -X POST http://localhost:8000/predict -H 'Content-Type: application/json' --data-binary @examples/predict_city.json
```

Ответ содержит predictions с disease=city/region, probability, prediction (порог 0.5) и фактическую model_version.

### GET /metrics, GET /health

/metrics возвращает метрики активных двух моделей. /health — список моделей и версию. До первого обучения predict/metrics возвращают 503; retrain доступен.

## Модели и экология

City: составной исход обследования — инсульт, СН, ИМ/стенокардия/ИБС, АГ или смерть. Region: объединение сердечно-сосудистых исходов, госпитализаций и смертей за период наблюдения. В обоих случаях цель равна 1 при наличии хотя бы одного учитываемого события. Точный состав исходов находится в dataset.py.

City использует 25 признаков city_filtered_5 с исключённым итоговым кодом холестерина. Числовой общий холестерин не добавляется взамен удалённого кода. Параметры: до 50 итераций, learning_rate=0.1, depth=8, веса классов [1, 0.578]; веса профессии=5, района=5, алкоголя=4, остальных признаков=1. Region: 26 признаков, до 2000 итераций, learning_rate=0.01, depth=8, веса классов [1, 0.28].

Справочники app/data/ecology содержат общие показатели по району/периоду и параметры моделей. При поступлении новых пациентов справочники не пересчитываются по их числу. Восстановление экологии выполнено по исходному Excel: медиана различных значений внутри район/пост/год/показатель, равновесное усреднение постов и среднее доступных лет. Сохранены исходные правила группировки и ручные подстановки лет; происхождение описано в reference_manifest.json.

Периоды city: 2013 — 2009–2013, 2017 — 2014–2017, 2019 — 2018–2019, 2021 — 2020–2021 (фактически главным образом 2020). Region использует доступные 2009–2020 годы. Новый календарный год автоматически не заменяется старым периодом.

Сохранено ограничение исходного городского блокнота: глюкоза 2019–2021 используется и для ранних обследований. Метрики описывают исторические составные исходы, а не подтверждают качество прогноза будущих событий.

## Сохранение и проверка

Модели и их согласованный снимок справочников хранятся в app/models/versions/<version>/. Указатель активной версии — app/models/CURRENT. Переключение после успешного обучения атомарное; процессы замечают новую версию при следующем запросе.

В проекте оставлен один текущий комплект. Исторические модели семи заболеваний, старые версии и файлы сравнительных запусков удалены. Последующие успешные переобучения создают новые версии.

Разделение 70/10/20 по пациентам общее для двух моделей: обследования одного человека не пересекают выборки. Validation выбирает итерацию; test используется для итоговых метрик. Seed и число потоков фиксированы.

| Модель | Признаки | Accuracy | ROC-AUC |
|---|---:|---:|---:|
| city | 25 | 72.46% | 0.7958 |
| region | 26 | 74.08% | 0.8140 |

```bash
uv run python -m unittest discover -s tests -v
```

Проверяются формат широкой таблицы, 13 профессий, целевые метки и обследования после смерти, разделение по пациентам, подготовка признаков CSV/JSON, округление, API retrain/predict, сохранение и загрузка моделей, обработка ошибок и переключение версии.

Настройки: ML_MODELS_DIR, ML_ECOLOGY_DIR, ML_MAX_UPLOAD_BYTES (по умолчанию 50 MiB). Каталог моделей должен быть доступен на запись.

## Подключение backend и frontend

Kotlin DTO, экспорт CSV и Vue-форма требуют нового контракта; этот каталог не изменяет БД и интерфейс. Для predict нужны model_kind, экологический период year и chronic_lung_disease. Для retrain передаётся широкая история с наблюдаемыми исходами; target рассчитывается сервисом. Кодировку алкоголя БД 1/2/3 нужно преобразовывать в ML 0/1/2. Старые коды профессий нельзя передавать без преобразования.
